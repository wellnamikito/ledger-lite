# ledger-lite

![Tests](https://github.com/wellnamikito/ledger-lite/actions/workflows/test.yml/badge.svg)

Pet-проект: минималистичный сервис для переводов между счетами, 
написанный как учебная демонстрация того, как правильно работать 
с деньгами и конкурентным доступом в бэкенде.

## Что умеет
- Создание владельца и счёта, пополнение, перевод между счетами, просмотр баланса
- Атомарные списания без ухода в минус (даже под конкурентной нагрузкой)
- Идемпотентность переводов через `Idempotency-Key`
- Явная модель статусов перевода с проверкой допустимых переходов
- Защита от удаления владельца с активными счетами
- Интеграционные тесты на реальном PostgreSQL (Testcontainers) + unit-тесты (Mockito)
- CI: тесты гоняются автоматически на каждый push и PR (GitHub Actions)

## Почему это интересно
Проект специально фокусируется на деталях, которые часто упускают 
в обычных CRUD-приложениях:
- `BigDecimal` + `NUMERIC(19,2)` вместо `double`, чтобы не терять копейки
- Атомарный `UPDATE ... WHERE balance >= :amount` вместо "прочитать-проверить-записать"
- Защита от deadlock через консистентный порядок блокировки счетов
- Тесты на гонки: параллельные переводы с одного счёта не должны 
  провести операцию дважды или увести баланс в минус

## Стек
Java 17, Spring Boot, PostgreSQL, Flyway, Hibernate, MapStruct, Docker Compose, Testcontainers

## Запуск
Приложение и база поднимаются одной командой:

```bash
docker compose up --build
```

API будет доступно на `http://localhost:8080`.

## Основные эндпоинты
| Метод | Путь | Описание |
|---|---|---|
| POST | `/owners` | Создать владельца |
| GET | `/owners/{id}` | Получить владельца |
| DELETE | `/owners/{id}` | Удалить владельца (409, если есть активные счета) |
| POST | `/accounts` | Создать счёт |
| GET | `/accounts/{id}` | Получить счёт |
| POST | `/accounts/{id}/deposit` | Пополнить счёт |
| GET | `/accounts/{id}/transfers` | История переводов по счёту (входящие и исходящие) |
| POST | `/transfers` | Перевести деньги (заголовок `Idempotency-Key` обязателен) |
| GET | `/transfers/{id}` | Получить перевод по id |

## Тесты
```bash
cd ledger-lite-app
mvn test
```
Интеграционные тесты сами поднимают отдельный контейнер PostgreSQL через Testcontainers — Docker должен быть запущен.
