# ledger-lite

Pet-проект: минималистичный сервис для переводов между счетами, 
написанный как учебная демонстрация того, как правильно работать 
с деньгами и конкурентным доступом в бэкенде.

## Что умеет
- Создание счёта, пополнение, перевод между счетами, просмотр баланса и истории операций
- Атомарные списания без ухода в минус (даже под конкурентной нагрузкой)
- Идемпотентность переводов через `Idempotency-Key`
- Явная модель статусов перевода с проверкой допустимых переходов
- Интеграционные тесты на реальном PostgreSQL (Testcontainers)

## Почему это интересно
Проект специально фокусируется на деталях, которые часто упускают 
в обычных CRUD-приложениях:
- `BigDecimal` + `NUMERIC(19,2)` вместо `double`, чтобы не терять копейки
- Атомарный `UPDATE ... WHERE balance >= :amount` вместо "прочитать-проверить-записать"
- Защита от deadlock через консистентный порядок блокировки счетов
- Тесты на гонки: параллельные переводы с одного счёта не должны 
  провести операцию дважды или увести баланс в минус

## Стек
Java, Spring Boot, PostgreSQL, Flyway, Hibernate, Docker Compose
